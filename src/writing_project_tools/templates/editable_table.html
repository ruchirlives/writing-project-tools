Saving and source references
  1. Open this HTML in Chrome or Edge. Click Open JSON and select the companion JSON beside it. Save writes changes to the selected file after browser permission. Save as creates a separate copy.
  2. Reopen JSON when you next open this HTML. Its embedded starting copy does not update. A browser recovery draft is separate from the JSON; Save is needed for a durable copy.
  3. If direct file access is unavailable, Open uses a chooser and Save downloads JSON. Move that downloaded copy into your project folder yourself.
  4. Save checks whether the connected file changed elsewhere before writing. If it did, reopen it to review changes or Save as a separate copy. Avoid simultaneous editing; cloud sync is not collaborative editing.
  5. View sources shows the retained source extracts and original row wording. Source notes and links are editable. Editing cells does not verify their wording against the sources. Extracts are snapshots and do not refresh when source files change.
  6. Word documents and other exports remain separate snapshots. Copy transfers the current table and source references; Print produces a printable view.
